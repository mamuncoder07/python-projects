# ⚙️ How It Works

The program checks for:

🔹 Password length  
🔹 Uppercase letters  
🔹 Lowercase letters  
🔹 Numbers  
🔹 Special characters  

Then it classifies the password as:

❌ Weak  
⚠️ Moderate  
💪 Very Strong
